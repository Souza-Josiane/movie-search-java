# 🎬 Java Movie Search

This is a simple Java console application that allows users to search for movies by title. The app fetches data using an external API and displays movie details such as title, year, and summary.

## 🔍 Features

- Search for movies by name
- Retrieve details such as title, release year, and plot
- Basic Java application structure using Maven

## 🛠️ Technologies

- **Java**
- **Maven**
- **HTTP Requests** (e.g., via `HttpURLConnection` or a library like `OkHttp`)
